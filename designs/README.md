# ClipShelf 落地页设计版本

这里包含三个不同风格的 ClipShelf 项目主页设计版本，每个版本都预留了截图位置供后续补充。

---

## 版本概览

### V1 - Glassmorphism (玻璃拟态)
**文件**: `v1-glassmorphism.html`

- **风格特点**: 深色主题 + 玻璃拟态效果 + 极光背景动画
- **视觉效果**: 流动的极光背景、毛玻璃卡片、浮动装饰元素
- **适用场景**: 追求现代感、科技感的产品展示
- **截图位置**:
  - Hero 区域的大型应用截图展示框
  - Gallery 区域的 4 个功能截图卡片（支持大图 + 小图混排）

---

### V2 - Bento Grid (便当盒布局)
**文件**: `v2-bento-grid.html`

- **风格特点**: 浅色主题 + 网格布局 + 极简设计
- **视觉效果**: 类 Apple Bento 风格的网格卡片、网格背景纹理
- **适用场景**: 信息密度高、功能点多的产品展示
- **截图位置**:
  - Bento 网格中的大型截图卡片
  - Gallery 区域的 4 个功能截图卡片
- **额外功能**: 包含完整的定价表格

---

### V3 - Editorial (编辑风格)
**文件**: `v3-editorial.html`

- **风格特点**: 杂志/编辑风格 + 衬线字体 + 高对比度
- **视觉效果**: 优雅的排版、装饰线条、非对称布局
- **适用场景**: 强调品牌调性、追求高端感的产品
- **截图位置**:
  - Hero 区域的应用展示框（带装饰线条）
  - Showcase 区域的 5 个功能截图卡片（混排布局）

---

## 截图占位符说明

所有版本中的截图占位符都使用统一的标识，你可以直接替换为真实截图：

```html
<!-- 截图占位符示例 -->
<div class="screenshot-placeholder">
    <svg>...</svg>
    <span>截图说明文字</span>
</div>
```

替换方式：
1. 删除 `screenshot-placeholder` div
2. 插入 `<img src="你的截图路径" alt="描述">`
3. 调整 CSS 以确保图片显示正常

---

## 技术说明

- 所有版本均为纯 HTML/CSS，无需构建工具
- 使用 Google Fonts 加载字体
- 完全响应式设计，支持移动端
- 可以直接在浏览器中打开预览

---

## 使用建议

1. **V1 Glassmorphism**: 适合强调技术感、现代感的品牌形象
2. **V2 Bento Grid**: 适合功能点多、需要清晰信息架构的产品
3. **V3 Editorial**: 适合追求设计感、品牌调性的高端产品
